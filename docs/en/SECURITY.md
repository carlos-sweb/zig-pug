## XSS Prevention

Cross-Site Scripting (XSS) is the most common web vulnerability. zig-pug provides automatic protection through HTML escaping.

### Automatic Escaping

**By default**, all interpolations are escaped:

```pug
- var userInput = "<script>alert('XSS')</script>"
p User said: #{userInput}
```

**Output (safe):**
```html
<p>User said: &lt;script&gt;alert(&#39;XSS&#39;)&lt;/script&gt;</p>
```

**Escaped characters:**
- `&` → `&amp;`
- `<` → `&lt;`
- `>` → `&gt;`
- `"` → `&quot;`
- `'` → `&#39;`

### Never Use Unescaped with User Input

**❌ DANGEROUS:**
```pug
// User provides: <img src=x onerror=alert('XSS')>
- var comment = req.body.comment
p !{comment}  // XSS VULNERABILITY!
```

**✅ SAFE:**
```pug
- var comment = req.body.comment
p #{comment}  // Automatically escaped
```

### When to Use Unescaped Interpolation

**Only use `!{}` with HTML you control:**

```pug
// ✅ SAFE - You control this HTML
- var safeHtml = "<strong>Important</strong>"
p !{safeHtml}

// ✅ SAFE - Generated by your template engine
- var renderedContent = renderMarkdown(trustedInput)
p !{renderedContent}

// ❌ DANGEROUS - User input
- var userBio = req.body.bio
p !{userBio}  // XSS!
```

### Attribute Escaping

Attributes are also escaped automatically:

```pug
- var malicious = '"><script>alert("XSS")</script><a href="'
a(href=malicious) Link
```

**Output (safe):**
```html
<a href="&quot;&gt;&lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt;&lt;a href=&quot;">Link</a>
```

## HTML Injection

### URL Validation

**❌ DANGEROUS:**
```pug
- var userUrl = req.query.url
a(href=userUrl) Click here
// User provides: javascript:alert('XSS')
```

**✅ SAFE:**
```pug
- function isSafeUrl(url) {
-   return url && (url.startsWith('http://') || url.startsWith('https://') || url.startsWith('/'));
- }
- var userUrl = req.query.url
- var safeUrl = isSafeUrl(userUrl) ? userUrl : '#'

a(href=safeUrl) Click here
```

### JavaScript URLs

**Block javascript: protocol:**

```pug
- function sanitizeUrl(url) {
-   if (!url) return '#';
-   var lower = url.toLowerCase().trim();
-   if (lower.startsWith('javascript:')) return '#';
-   if (lower.startsWith('data:')) return '#';
-   if (lower.startsWith('vbscript:')) return '#';
-   return url;
- }

- var link = sanitizeUrl(userProvidedUrl)
a(href=link) Safe Link
```

### Data URLs

**Be cautious with data: URLs:**

```pug
// ❌ DANGEROUS
img(src=userProvidedDataUrl)

// ✅ SAFE - Validate format
- function isSafeDataUrl(url) {
-   return url && url.startsWith('data:image/');
- }
- var imgSrc = isSafeDataUrl(userImg) ? userImg : '/placeholder.png'
img(src=imgSrc)
```

## Code Injection

### Eval Injection

**❌ DANGEROUS:**
```pug
// Never evaluate user input
- var userCode = req.body.code
- eval(userCode)  // CODE INJECTION!
```

**No safe way** to execute arbitrary user code. Don't do it.

### Expression Injection

zig-pug templates are compiled, not evaluated at runtime, so expression injection is not possible through normal template variables.

**However**, be careful with template generation:

**❌ DANGEROUS:**
```javascript
// Server-side (Node.js)
const template = `p Hello #{${userInput}}`;  // Template injection!
const html = compile(template, data);
```

**✅ SAFE:**
```javascript
// Pass user input as variable, not template code
const template = `p Hello #{userName}`;
const html = compile(template, { userName: userInput });
```

## Best Practices

### 1. Always Escape User Input

**Default behavior (safe):**
```pug
p #{userInput}
p= userInput
```

**Unescaped (only for trusted content):**
```pug
p !{trustedHtml}
p!= trustedHtml
```

### 2. Validate Input Before Use

```pug
- function validateEmail(email) {
-   return email && /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
- }

- var email = userEmail
- if (!validateEmail(email)) {
-   throw new Error('Invalid email');
- }

p Email: #{email}
```

### 3. Whitelist, Don't Blacklist

**❌ BAD (blacklist):**
```pug
- function sanitize(input) {
-   return input.replace('<script>', '');  // Incomplete!
- }
// Bypassed by: <scr<script>ipt>
```

**✅ GOOD (whitelist):**
```pug
- function sanitize(input) {
-   return input.replace(/[^a-zA-Z0-9 ]/g, '');  // Only allow safe chars
- }
```

### 4. Use Content Security Policy (CSP)

```pug
doctype html
html
  head
    meta(http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self' https://trusted-cdn.com")
```

### 5. Sanitize HTML with a Library

**For user-generated HTML content, use a sanitization library:**

```javascript
// Server-side (Node.js)
const sanitizeHtml = require('sanitize-html');

const clean = sanitizeHtml(userHtml, {
  allowedTags: ['b', 'i', 'em', 'strong', 'a', 'p'],
  allowedAttributes: {
    'a': ['href']
  }
});

compiler.setString('userBio', clean);
```

```pug
// Template
p.user-bio !{userBio}  // Safe - already sanitized
```

### 6. Escape in Output Context

Different contexts need different escaping:

**HTML context:**
```pug
p #{userInput}  // HTML-escaped
```

**JavaScript context:**
```pug
script.
  var userName = "#{userInput.replace(/"/g, '\\"')}";  // JSON escape
```

**Better - use JSON:**
```pug
script.
  var userName = #{JSON.stringify(userInput)};
```

### 7. Avoid Inline Event Handlers

**❌ BAD:**
```pug
button(onclick=userProvidedHandler) Click  // Injection risk!
```

**✅ GOOD:**
```pug
button#myButton Click

script.
  document.getElementById('myButton').addEventListener('click', function() {
    // Safe event handling
  });
```

### 8. Validate File Paths

**❌ DANGEROUS:**
```pug
// Path traversal attack
// User provides: ../../../../etc/passwd
- var file = userProvidedPath
include #{file}  // FILE DISCLOSURE!
```

**✅ SAFE:**
```pug
- function validatePath(path) {
-   var allowedPaths = ['header', 'footer', 'sidebar'];
-   return allowedPaths.indexOf(path) !== -1 ? path : 'header';
- }

- var component = validatePath(userChoice)
include components/#{component}.zpug
```

## Security Checklist

### Template Development

- [ ] All user input uses escaped interpolation `#{}`
- [ ] Unescaped `!{}` only used with trusted content
- [ ] URLs validated before use in `href`
- [ ] No `eval()` of user input
- [ ] File paths validated against whitelist
- [ ] Input validated before processing
- [ ] Length limits enforced on user input

### Server-Side (Node.js)

- [ ] User input never concatenated into template strings
- [ ] HTML sanitization library used for user HTML
- [ ] Content Security Policy (CSP) headers set
- [ ] HTTPS enforced
- [ ] Cookies set with `httpOnly` and `secure` flags
- [ ] Rate limiting implemented
- [ ] Input validation on API endpoints

### Deployment

- [ ] Templates compiled in production (not dynamic)
- [ ] Error messages don't leak sensitive info
- [ ] Debug mode disabled in production
- [ ] Dependency security audit passed (`npm audit`)
- [ ] Template files have proper permissions
- [ ] Logs don't contain sensitive data

## Common Vulnerabilities

### 1. Reflected XSS

**Vulnerable:**
```javascript
// Server
app.get('/search', (req, res) => {
  const query = req.query.q;
  const html = compile('p You searched for: #{query}', { query });
  res.send(html);
});
```

**Attack:**
```
/search?q=<script>alert('XSS')</script>
```

**Safe (automatic escaping):**
```html
<p>You searched for: &lt;script&gt;alert(&#39;XSS&#39;)&lt;/script&gt;</p>
```

### 2. Stored XSS

**Vulnerable:**
```javascript
// User submits malicious comment
const comment = "<img src=x onerror=alert('XSS')>";
db.save({ comment });

// Later displayed unescaped
const html = compile('p !{comment}', { comment: savedComment });
```

**Safe:**
```javascript
// Sanitize before storage
const clean = sanitizeHtml(comment);
db.save({ comment: clean });

// Or use escaped interpolation
const html = compile('p #{comment}', { comment: savedComment });
```

### 3. DOM XSS

**Vulnerable:**
```pug
script.
  var data = location.hash.substring(1);
  document.write(data);  // XSS!
```

**Safe:**
```pug
script.
  var data = location.hash.substring(1);
  document.getElementById('output').textContent = data;  // Text content, not HTML
```

### 4. Open Redirect

**Vulnerable:**
```pug
- var redirect = req.query.next
a(href=redirect) Continue
```

**Attack:**
```
?next=https://evil.com
```

**Safe:**
```pug
- function isSafeRedirect(url) {
-   return url && url.startsWith('/');  // Only relative URLs
- }
- var redirect = isSafeRedirect(req.query.next) ? req.query.next : '/'
a(href=redirect) Continue
```
