# Notas Importantes para Claude Code

## ⚠️ ESTRUCTURA DE DISTRIBUCIÓN - NO MODIFICAR

**NUNCA cambiar esta estructura sin consultar primero:**

```
bin/              ← DISTRIBUIBLE (git tracked) - Binarios CLI
libs/             ← DISTRIBUIBLE (git tracked) - Librerías dinámicas
nodejs/           ← DISTRIBUIBLE (git tracked) - Todo para npm
zig-out/          ← TEMPORAL (gitignored) - Solo artefactos de build
```

### Reglas Críticas:

1. **zig-out/ NO se distribuye**
   - Es temporal, está en .gitignore
   - Se puede eliminar sin problema
   - `build-all.sh` COPIA de zig-out/ a bin/libs/

2. **bin/ y libs/ SÍ se distribuyen**
   - Están trackeados en git
   - Los usuarios descargan estos archivos
   - NUNCA agregarlos a .gitignore

3. **build-all.sh funciona correctamente**
   - Compila a zig-out/ (temporal)
   - Copia a bin/ y libs/ (distributable)
   - No modificar sin entender DISTRIBUTION.md

### Si el usuario dice "los binarios van a zig-out/"

**Respuesta correcta:**
- Eso es normal y correcto
- build-all.sh COPIA de zig-out/ a bin/
- Los archivos finales están en bin/ y libs/
- zig-out/ son solo temporales
- Leer DISTRIBUTION.md antes de cambiar

### Si el usuario pide reorganizar bin/libs/

**Respuesta:**
- Ya está reorganizado en sesión anterior
- Ver DISTRIBUTION.md para entender la estructura
- No repetir el trabajo ya hecho
